# Dillon Krotz

Personal site: a pixel-art MMORPG, DungeonSmithy, DungeonGame, Air Force service, skills and contact.

Live at https://krotz.dev. The `CNAME` file tells GitHub Pages to serve the site at that address.

## How it is built

One static `index.html` with no build step. Pictures and clips live in `assets/`:

- `assets/bm/` clips and art from the pixel-art MMORPG
- `assets/ds/` DungeonSmithy clips, scene cards, and the images used on dungeonsmithy.com
- `assets/dg/` DungeonGame renders
- `assets/ui/` banner art and logos

To change the site, edit `index.html` and push.
